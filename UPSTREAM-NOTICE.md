# Procedencia del código

Este proyecto se desarrolla dentro de la copia local del repositorio `Tangerine-Community/Tangerine`, bajo `../`. La fuente upstream mantiene su licencia GPLv3 y sus avisos. La interfaz de DIAL es un módulo nuevo; en esta versión no integra los componentes Angular ni los servicios CouchDB de Tangerine.

- Proyecto upstream: https://github.com/Tangerine-Community/Tangerine
- Licencia: GPLv3 (`../LICENSE.txt` y `COPYING`)
- Marca: DIAL es una marca independiente de este módulo; no incluye el logotipo de Tangerine.
